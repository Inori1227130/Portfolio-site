# Portfolio-site

1.概要
このリポジトリはManaの今までの経験を活かして製作したポートフォリオのコードをまとめたものです。
Webデザイン・Web開発の学習経験を整理し、実際に動くプロダクトとして公開を目的としています。
このポートフォリオサイトはHTML / CSS / JavaScript を使用して制作しました。  
作品一覧やプロフィール、コンタクトフォームなどを掲載しています。また、レスポンシブ対応をしており、スマホ表示にも対応しています。

2.使用技術
・HTML
・CSS
・JavaScript
・Git/GitHub

3.工夫した点
・このポートフォリオを初めてみる人でも見やすいようにシンプルな構成にしました。また、配色も試行錯誤を行いながら調整しました。
・レスポンシブ対応にしたことにより、パソコンだけでなくスマホの種類によってもサイトを正常に表示させました。

4.改善点
・URL設定がまだ終わっていないので、終わらせるようにしたいと考えています。
・作品一覧を中心に余白を調整するなど更に見やすいサイトにしたいと考えています。
・contactの申し込みを送るボタンを押した時に、申し込み完了ページに移動できるように改善を行いたいと考えています。
